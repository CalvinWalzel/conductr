Idle Claude Code sessions hibernate to free memory, and a button loads Claude Code updates. Both need the resume hooks from setup.

- A Claude Code session that sits idle in a hidden tab for 30 minutes stops. It resumes when you open its tab. Settings changes the time, and 0 turns it off.
- Right-click a tab in the sidebar to hibernate its session at once. A hibernated tab keeps its name and shows a moon.
- After a reboot, a session resumes when you open its tab, not all at once.
- A Claude button next to Settings shows while sessions run an older Claude Code than is installed. It restarts the ones that are not busy.
- An unsent draft and a background task are lost when their session hibernates.
