Hibernation no longer costs you a draft or a background command.

- A session with an unsent draft or a running background command does not hibernate, and the Claude button does not restart it.
- A new session with no messages does not hibernate. It could not resume.
- Right-click Hibernate asks before it stops a session with a draft.
- Conductr settings, Changelog has a Check for updates button. It also checks for a Claude Code update.
